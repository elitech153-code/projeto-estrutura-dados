# Parte Java — Missão Estelar (N1)

Código-fonte em `src/`. Requisito: JDK 17 ou superior.

Para compilar e executar, a partir de `java/src` (no terminal):

```bash
javac -encoding UTF-8 -d ../out -sourcepath . Main.java
java -cp ../out Main
```

Observações:
- Execute pelo terminal, pois o programa lê as opções digitadas no teclado.
- Se houver arquivos `.class` dentro de `src`, apague-os antes de compilar.
